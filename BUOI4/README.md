# BUOI4 – Bài 4: Bảo mật Web App và API

Thư mục này chứa hai bài lab của Bài 4:

- `lab1/web-vuln-scanner`: công cụ minh họa kiểm tra XSS, SQL Injection, CSRF và SSRF.
- `lab2/jwt-security-tools`: bộ công cụ minh họa JWT, token manager, API Gateway và xác thực Bearer token.

Mỗi lab có README riêng, mã nguồn, bài kiểm thử và thư mục `images` chứa ảnh bằng chứng thực hành.
